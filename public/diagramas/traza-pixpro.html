¿Cómo encuentro dónde se atoró un lote entre cinco servicios?

Long image

A

Answer

Con una traza distribuida: cada servicio mide su parte (un span) y pasa el mismo trace id al siguiente, así se ve el viaje completo; las métricas dicen que algo va mal y los registros explican qué pasó en un punto.

  1. Métricas, registros y trazas son las tres señales de observabilidad que estandariza OpenTelemetry.1
  2. El trace id viaja entre servicios en la cabecera estándar traceparent.2
  3. Las cuatro señales doradas son latencia, tráfico, errores y saturación.3

¿Cómo viaja el trace id?

Diagram structure
  • SPA spa
  • Proxy / gateway gw
  • API de lotes api
  • Broker broker
  • Notificaciones notif
  • spa → gw · POST /lotes · traceparent 4bf9…
  • gw → api · mismo traceparent
  • api → broker · LoteCreado + traceparent
  • broker → notif · ImagenProcesada + traceparent
  • notif → spa · avance por WebSocket
  1. SPA ↗

    Crea el trace id y lo manda en la cabecera traceparent.

  2. Gateway ↗

    No lo cambia: solo agrega su propio span.

  3. Broker ↗

    El trace id va dentro del evento para no perder el hilo.
